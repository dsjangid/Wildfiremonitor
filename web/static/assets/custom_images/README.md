# Custom Image Asset Slots

Drop custom agency emblems, topography textures, orthophoto aerial maps, and iconography here.

### Standard Slot Names:
- `agency_logo.png`: Replaces default Montesinho Command Center logo in top header.
- `park_aerial.jpg`: Custom satellite orthophoto draped onto the 3D terrain grid.
- `incident_commander_badge.png`: Command status badge.
