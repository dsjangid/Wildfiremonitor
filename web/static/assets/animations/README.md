# Animation Asset Slots

Drop your custom animation files here to seamlessly integrate them into the Wildfire Command Center HUD.

### Supported Formats:
- **SVG Animations**: Standard animated SVGs (CSS keyframes or SMIL).
- **Lottie JSON**: Vector-based JSON animation definitions.
- **WebM / GIF**: Looping video/animation clips with transparency.

### Standard Slot Names:
- `radar_sweep.svg`: HUD background scanning overlay.
- `fire_pulse.svg`: High-risk cell warning beacon indicator.
- `crew_deploy.svg` or `crew_deploy.json`: Animation played upon crew dispatch calculation.
